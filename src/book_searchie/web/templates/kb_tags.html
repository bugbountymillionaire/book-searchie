Tags and backup

Tidy your KB's tags and entry titles, see the books you've finished researching, and back it all up. To reorder, rename or merge sub-headings, use Sub-headings.

Tags

Rename a tag to fix its spelling. Renaming it to a tag you already have merges the two, and the old name is kept as another name for it. Other names (such as Cephalalgia for Headache) find the tag when you search or type them.

Entries

Back up your KB

Your KB is your own work, and unlike the search index it can't be rebuilt from your books. It's kept in {{ notes_path }}: include that file in your backups.

{% if total %}

Download a backup (JSON) Markdown, book text marked Markdown, book text left out

The JSON file has everything, and can be restored with book-searchie notes import FILE. The Markdown download is a zip with one file per entry and its sub-headings as headings: a first draft for a website or book. Text you saved from a book is either marked, so you can see what still needs rewriting in your own words, or left out. From the command line: book-searchie notes export backup.json, or book-searchie notes export --format md FOLDER (add --book-text omit to leave it out).
